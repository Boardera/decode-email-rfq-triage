# Contributing

This repository is a demonstration of building on the
[Boardera Decode API](https://boardera.io), shared as-is. It is maintained on
a best-effort basis — issues and pull requests are welcome, but there is no
support commitment or release schedule.

## Before opening a PR

```sh
npm install
npm run typecheck
```

Keep changes small and focused. If you are proposing a behaviour change
(e.g. new report content or email format), open an issue first so we can
agree on direction.

## Questions about the Decode API itself

API questions (keys, plans, endpoints, schema) are handled through your
Boardera account, not this repo — see <https://boardera.io>.
